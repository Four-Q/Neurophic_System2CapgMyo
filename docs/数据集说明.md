# CapgMyo DB-a 数据集说明

## 数据集简介

[CapgMyo DB-a](https://figshare.com/articles/dataset/Data_from_Gesture_Recognition_by_Instantaneous_Surface_EMG_Images_CapgMyo-DBa/7210397) 包含 18 名受试者完成 8 类手势的高密度表面肌电（HD-sEMG）数据，每类手势重复 10 次，共 1,440 个 trial。

每个 trial 含约 1 s、1,000 Hz 采样的 128 通道 HD-sEMG 信号，电极排列为 `8 × 16`。本项目使用官方公开预处理版本（Figshare v1，DOI `10.6084/m9.figshare.7210397.v1`）。

使用数据时请同时遵守数据来源页面所列许可与引用要求。

## 数据划分

本项目采用固定随机种子 `42` 生成并锁定的重复编号划分，18 名受试者都会出现在三个子集中：

| 子集 | 重复编号 | trial 数量 |
| --- | --- | ---: |
| 训练集 | 1、3、4、5、6、7、8 | 1008 |
| 验证集 | 10 | 144 |
| 测试集 | 2、9 | 288 |

该方式属于受试者内划分，适用于评估已见受试者的手势识别效果，不应将其误认为跨受试者泛化划分。

## 样本格式

每个文件命名形式为 `s{subject_id}_g{gesture_id}_r{repetition_id}.pt`，例如 `s01_g03_r07.pt` 表示受试者 1、手势 3、第 7 次重复。文件内容为字典，字段如下：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data` | `torch.float32` | 原始数据 shape 为 `[1000, 1, 8, 16]`；正负分离后为 `[1000, 2, 8, 16]` |
| `label` | `torch.int64` | 分类标签，范围 0～7 |
| `subject_id` | `torch.int64` | 受试者编号，范围 1～18 |
| `gesture_id` | `torch.int64` | 手势编号，范围 1～8 |
| `repetition_id` | `torch.int64` | 重复编号，范围 1～10 |

## 正负双通道编码

为保留 sEMG 极性并向后续 CSNN 提供非负输入，原始信号按下式分离：

```text
positive = max(x, 0)
negative = max(-x, 0)
```

输出通道顺序固定为 `[positive, negative]`，可通过 `x = positive - negative` 精确恢复原始信号。该过程不执行滑窗、裁剪、重新归一化或脉冲编码。

## 后续处理

在正负分离数据基础上，本项目的 `src/data_prepare` 进一步生成：

- **原始极性分箱数据**（T=200，float32）：`bin(t) = floor(t * T / 1000)` 分箱取最大值；
- **Vin 输入编码脉冲**（T=200，bool）：幅值 → 电压映射 → `System_with_TIA` 电路；
- **Delta 编码脉冲**（T=200，bool）：帧间绝对差分 + 阈值化；
- **Threshold 编码脉冲**（T=200，bool）：幅值 + 阈值化。

各编码方式详见 [`docs/`](.) 目录下的对应文档。
